# ポケスリ料理チェッカー

ポケモンスリープで、手持ちの食材から「今作れる料理」と「あと少しで作れる料理」をすぐに調べるためのスマホ向けWebアプリです。

## 使い方

1. 上のボタンで今週の料理（カレー / サラダ / デザート）を選び、鍋の容量を入れる
2. 在庫を入れる
   - 「📷 スクショから読み取る」でバッグの「食材」画面のスクショを選ぶと、個数を自動で読み取る（1画面に入りきらないときは複数枚まとめて選べる）。確認画面で直してから反映できる。写っていない食材は0になる
   - 食材タイルをタップで +1
   - 長押しで数字パッド（±1・+5・+10・直接入力）
3. 「作れる」「あと少し」「全レシピ」のタブで結果を見る（基本エナジーの高い順）
   - 「あと少し」では足りない食材と個数が赤で出て、食材タイルも赤枠になる
   - 「全レシピ」では今のカテゴリの全料理を、足りない食材つきで出す。鍋に入らない料理は薄く表示。食材のアイコンを選ぶと、その食材を使う料理に絞り込める

在庫と設定はスマホのブラウザに保存されるので、次に開いたときは変わった分だけ直せば使えます。
スマホのブラウザで「ホーム画面に追加」すると、アプリのように開けます。

## レシピデータ

`src/data/recipes.ts`（料理）と `src/data/ingredients.ts`（食材）にまとめています。
新しい料理が追加されたら、ここに1行足すだけで反映されます。

料理名・必要個数・基本エナジーは [pks.raenonx.cc](https://pks.raenonx.cc/ja/meal) から取り、必要個数は [serebii.net](https://www.serebii.net/pokemonsleep/dishes.shtml) とも照合しています（2026年9月27日時点、全78品）。

## スクショ読み取りのしくみ

[Tesseract.js](https://github.com/naptha/tesseract.js) でスマホのブラウザの中だけで文字を読み取ります（画像はどこにも送りません）。
「x13」のような個数と、その下の食材名を見つけて対応づけます（`src/ocr/parse.ts`）。
エンジンと日本語データ（初回だけ約6MBのダウンロード）はこのサイト自身から配信していて、`npm run dev` / `npm run build` の前に `scripts/copy-ocr-assets.mjs` が npm パッケージから `public/ocr/` にコピーします。

## 開発

```sh
npm install
npm run dev     # 開発サーバー
npm test        # 判定ロジックとデータのテスト
npm run build   # dist/ に出力
```

`main` ブランチに push すると GitHub Actions で GitHub Pages に公開されます
（リポジトリの Settings → Pages → Source を「GitHub Actions」にしておく必要があります）。
